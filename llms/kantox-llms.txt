# Kantox

> Kantox is a foreign-exchange (FX) risk management and Currency Management Automation software company, part of BNP Paribas. Its Dynamic Hedging platform automates the pre-trade, trade and post-trade FX workflow — exposure collection, rules-based hedge execution, dynamic pricing with live mid-market rates across 130+ currencies, and end-to-end reporting. Companies connect ERP/TMS/trading systems via REST API or SFTP. Kantox is authorised by the UK FCA and regulated by the Bank of Spain.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Kantox surface. Kantox publishes no public API reference or OpenAPI specification; API access is provisioned to customers during onboarding.
